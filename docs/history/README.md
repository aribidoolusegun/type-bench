# Historical images and recordings

Everything in this folder was captured from **earlier builds** of Type Bench, in October 2026. It's kept as a record of how the interface developed, and for before-and-after comparisons. It does **not** show the current interface: these builds predate small-screen headings, the separate body and heading weights and the single Preview width control.

For images of the current interface, see [`docs/screenshots`](../screenshots/) and [`docs/media`](../media/).

| Folder | What it shows |
| --- | --- |
| [`screenshots/`](screenshots/) | The earlier showcase set: Editorial, Dashboard (with and without test content), font picker, export dialog, phone layouts and the sidebar CSS panel |
| [`before-after/`](before-after/) | Comparisons from the phone-workspace and export-dialog redesign, at identical sizes. "Before" and "after" both refer to earlier builds |
| [`media/`](media/) | Recordings: a 29-second complete workflow, revealing overflow findings by pointer and keyboard, and font selection, resizing and copy feedback (the grey dot marks the pointer and is drawn only for the recording) |
| [`beta/`](beta/) | Images and a recording made for the first beta: default desktop view, phone view, and overflow recovery |
| [`first-use/`](first-use/) | The first-use introduction on desktop and phone, and a recording of "See how it works", from the release that introduced them |
