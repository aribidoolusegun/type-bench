# Type Bench beta: feedback guide

Thank you for trying Type Bench. This beta has one question: **can a designer create a type system, check it at a narrow width and export something they would actually use?**

The session takes about 20 minutes. Please think aloud as you go. If something is unclear, say so. Confusion is exactly what we want to learn about, and nothing you do counts as a mistake.

## Before you start

- Use a desktop or laptop browser. Optionally, try a phone afterwards.
- Open Type Bench at the link you were sent.
- Settings save in your browser, so the next visit continues where you left off. **Reset** in the header returns to the defaults.

## Tasks

### 1. Create a type system (about 8 minutes)
Choose a font and adjust the base size, scale ratio, body line height and weight until you have a system you would be happy to use on a real product. Name it with the field at the top of the page.

### 2. Inspect it at a narrow width (about 7 minutes)
Narrow the preview to a phone width, using the width presets, the width field or the blue handles beside the canvas. Look at the Editorial, Dashboard and Mobile previews. Use the **Diagnostics** panel to find anything that doesn't fit, and its **Show** action to locate it. Change your settings if you want to.

### 3. Export CSS (about 5 minutes)
Open **Export** and copy or download the CSS. Explain how you would use it in a project, and what you would need to change or add.

## For the person running the session

- Don't demonstrate features or name controls before the participant finds them. If they're stuck for two minutes, ask what they're looking for, then help, and note it as "with help".
- Record what happened, not what you expected. Leave empty fields empty.
- Don't collect names, emails or screen recordings without the participant's consent.
- Report bugs separately, with the browser, the steps that led to them and a screenshot if possible.
