# Security policy

Type Bench runs entirely in the browser: there is no backend, no account and no data sent anywhere. Settings are stored only in your browser's local storage.

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/aribidoolusegun/type-bench/security/advisories/new)).

Include what you found, how to reproduce it, and which version (the live site, or a commit) is affected. You'll get a reply as soon as the report has been reviewed.

## Supported versions

Only the latest version, deployed at https://type-bench.vercel.app and on the `main` branch, receives fixes.
